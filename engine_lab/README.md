# Engine Lab

4ストロークのガソリンエンジン(1気筒、0.5 L)の熱サイクルを調整して、熱効率やトルクを最大にするゲーム。

- クランク角で積分する1ゾーンモデル(理想気体、Wiebe燃焼、Woschni型の壁面熱損失、Livengood–Wu のノッキング積分)。
- シリンダーの動き、P-V線図(囲まれた面積 = 仕事)、燃料エネルギーの行方(仕事・摩擦・ポンプ損失・冷却損失・排気熱・未燃)を表示。
- 全4ステージ: 圧縮比(ノッキングの壁)→ 点火時期(MBT)→ ミラーサイクル(遅閉じ)→ 総合設計(過給)。
- ノッキングが起きたらスコア0。スコア = 基準(0点)〜最適付近(1000点)に換算。

実行: `engine_lab/index.html` をブラウザで開く。テスト: `node engine_lab/tests/solver.test.js`
