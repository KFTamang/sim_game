# 題材の候補

選定基準:
- 直感に反する(「こうすれば良くなるはず」が外れる)
- トレードオフがある(性能を上げるとコストも上がる)
- ブラウザで軽く解ける(1回の評価が1秒以内)
- **2次元の自由形状が解になる**(スカラー最適化は計算機で解けるので優先度を下げる)

## 優先(2D形状で最適化できるもの)

| 題材 | 形状の自由度 | スコア | 身につく直感 |
|---|---|---|---|
| 橋・トラス (実装済み) | 部材の配置・接続 | 耐荷重 ÷ コスト | 三角形、力の流れ、座屈 |
| 熱伝導パス (実装済み: `heat_lab/`) | 格子上に高伝導材を塗る | 熱抵抗 × 使用量 | 枝分かれ構造(根・血管)が最適になる |
| PCB配線のインピーダンス整合 | 線幅の分布、テーパー、スタブ、ビア位置 | 反射の小ささ × 面積 | 幅の急変は反射、滑らかなテーパーが効く |
| ヒートシンク形状 | フィンの輪郭 | 冷却量 ÷ 材料 | 詰めすぎると流れが止まる |
| 翼・流線形 | 2D断面の輪郭 | 抗力・揚力比 | 剥離、後縁の尖らせ方 |
| 防音壁・吸音構造 | 断面形状、穴、キャビティ | 減衰量 ÷ 質量 | 共鳴、隙間の致命性 |
| 波の集束・遮蔽 | 反射板・障害物の2D配置 | 目標点の振幅 | 干渉・回折 |
| クラッシャブルゾーン | 構造形状(波形・リブ) | 衝撃加速度ピークの低さ | 計画的な座屈 |
| 電磁石・磁気回路 | 鉄心形状とギャップ | 吸引力 ÷ 重量 | 磁気飽和、漏れ磁束 |
| 流路・パイプ分岐 | 流路壁形状 | 圧力損失 | 剥離、滑らかな接続 |
| レンズ・ミラー形状 | 曲線 | 集光度 | 収差、放物面 |

## 共通ソルバー案
- 質量バネ/梁要素: 橋、タワー、クラッシャブル
- 2D格子の拡散・波動(差分法): 熱、音、静電場・磁場
- 格子ボルツマン法: 流体
- 1D伝送線路(電信方程式): インピーダンス整合
