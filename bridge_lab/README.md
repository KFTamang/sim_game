# Bridge Lab(橋の強度)

`sim_game` の第1作。

2次元トラス橋を設計し、荷重テストで壊れるまで負荷をかけます。

- 格子点から格子点へドラッグして部材を描く(丸棒 / パイプ、5段階の太さ)
- 設計中も**リアルタイムに耐荷重・コスト・部材ごとの使用率**を表示(青=引張 / 赤=圧縮)
- ◎ が「最初に壊れる部材」。引張降伏か座屈かも表示される
- **スコア = 耐荷重(kN) ÷ コスト × 1000**(目標荷重を満たし、予算内のときのみ)
- 荷重テストでは徐々に荷重をかけ、破断後の連鎖崩壊をアニメーション
- テスト後に結果を X(旧Twitter)へ投稿するボタン(投稿画面が開くだけで、自動投稿はしません)

### 遊び方

`index.html` をブラウザで開くだけ(ビルド不要、外部依存なし)。

ローカルサーバで開く場合: `bridge_lab/` で `npm run serve` → http://localhost:8000

| 操作 | 内容 |
|---|---|
| ドラッグ | 部材を描く |
| 右クリック / 消すツール | 部材を削除 |
| 塗替ツール | 部材の種類・太さを変更 |
| 1 / 2 / 3 | 描く / 塗替 / 消す |
| Q / W、↑ / ↓ | 丸棒 / パイプ、太さ |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Space | 荷重テスト開始 / 停止 |

### 物理モデル

- ピン接合トラス(部材は軸力のみ)を**直接剛性法**で線形解析 (`js/solver.js`)
- 引張限界: 降伏応力 × 断面積
- 圧縮限界: オイラー座屈と降伏の合成 `1/Pc = 1/Py + 1/Pe`, `Pe = π²EI/L²`
- 構造は線形なので、自重(固定)と単位活荷重の2回の解析から、
  最初の部材が壊れる荷重係数を**厳密に**求める
- 両端のアンカーは完全固定(水平反力あり → アーチ的な挙動も出る)
- 道路(y=0)は1mごとに節点があり、支えのない区間は最大2m(床版は梁として荷重を両端の節点に配分)
- 曲げ・接合部の強度・動的効果は無視(あくまで直感づくりが目的)
