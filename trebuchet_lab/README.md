# Trebuchet Lab

カウンターウェイト式の投石機(トレビュシェット)を設計して、弾をできるだけ遠くへ(または狙った距離へ)投げるゲーム。

- 腕・吊り下げ式の錘・スリングの3つの角度を自由度とする、平面のラグランジュ力学モデル(4次ルンゲ・クッタ、1 ms 刻み)。弾が最初に地面を引きずられる段階は、拘束力(ラグランジュ乗数)付きで解く。
- スリングが腕の延長線に対してなす角(放出角)で、ピンから弾が外れる瞬間を決める。放出後は放物運動。
- 上の図で機械の動き、下の図で全体の軌道と着地点(試行の履歴付き)を表示。錘のエネルギーのうち弾に渡った割合も見られる。
- 全5ステージ: てこの比 → スリングの長さ → 吊り下げ式の錘 → 狙い撃ち(目標 220 m) → 総合設計。
- 錘や腕が地面に当たる、弾が放出前に落ちる、などの失敗条件あり。スコア = 飛距離を基準(0点)〜最適付近(1000点)に換算。

実行: `trebuchet_lab/index.html` をブラウザで開く。テスト: `node trebuchet_lab/tests/solver.test.js`(エネルギー保存・各ステージの性質を確認)
