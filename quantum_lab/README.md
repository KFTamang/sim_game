# Quantum Lab

量子コンピュータのゲート(H, X, Y, Z, S, T, CNOT, CZ, SWAP)を回路に並べて、目標の量子状態(または目標の動作)を作るパズル。

- 1〜3量子ビットの状態ベクトルを厳密にシミュレーション(ビルド不要、外部依存なし)。
- 状態はブロッホ球と確率・位相の棒で表示。もつれると矢印が球の内側に縮む。
- 一致度(忠実度)99.9%以上で合格。スコア = 1000 × 最小コスト ÷ あなたのコスト。
- ゲートコスト: H/X/Y/Z/S = 1、T = 2、CNOT/CZ = 2、SWAP = 3、CCZ = 6。
- 全17ステージ(反転 → 位相 → 基底変換 → T → ベル状態 → 一重項 → CZ から CNOT → SWAP → GHZ → グローバー探索: 重ね合わせ、オラクル、平均での折り返し、4候補・8候補の探索)。

実行: `quantum_lab/index.html` をブラウザで開く。テスト: `node quantum_lab/tests/solver.test.js`
