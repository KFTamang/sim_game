# Entropy Lab

粒子のビームを、鏡やざらざらの壁で散らして「エントロピーが増える」様子を体感するゲーム。

- 箱の中の1000粒子。最初はほぼ平行なビーム(とても秩序だった、低エントロピーの状態)。
- 箱を「位置のマス × 向き」に区切って、粒子の分布の乱雑さ `S = −Σ p ln p`(粗視化エントロピー)を数える。100% = 完全に混ざった状態。
- 壁を塗って、S が 90% に届くまでの時間を短くする。スコア = 1000 × 基準時間 ÷ あなたの時間。
- **鏡**(コスト 1): 反射するだけ。平らな壁では混ざらないが、丸い障害物は小さな角度差を拡大してカオス的に散らす。
- **ざらざらの壁**(コスト 3): 拡散反射(ランベルトの余弦則)。来た向きを忘れる。
- 「⏪ 時間反転」: 鏡だけの世界は完全に可逆(来た道を逆にたどる)。ざらざらの壁があると戻れない。

実行: `entropy_lab/index.html` をブラウザで開く。テスト: `node entropy_lab/tests/solver.test.js`
