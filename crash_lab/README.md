# Crash Lab — 衝突を受け止める構造を作る

質量1トンの乗員室が壁に突っ込む。壁と乗員室の間に材料を塗って、**つぶれながらエネルギーを吸収する構造(クラッシャブルゾーン)**を設計し、
乗員室にかかる**最大の減速度(G)**をできるだけ小さくするゲーム。

## 遊び方
`index.html` をブラウザで開く(ビルド不要)。

- 材料を塗ると、**衝突の結果(減速度の波形)がすぐ下のグラフに出る**。「▶ 衝突テスト」でスローモーション再生して提出。
- 「潰れ具合を表示」で、各セルがどれだけ潰れたかが見える(青 = ほぼ未使用 = 重りでしかない)。
- スコア = 理想との近さ(η = 理想の一定減速度 ÷ 最大G)× 1000 ×(1 + 0.5 × (1 − コスト/予算))。上限Gを超えたり予算超過だと0点。

## 身につく直感
- 止めるのに必要な仕事は **力 × 距離**。距離を使い切って**力を一定**にするのが理想(グラフの緑線)。
- 力が足りないと**底づき**(潰れきって壁に激突)、大きすぎるとGが跳ね上がる。
- 部材は座屈する瞬間に**最大の力(初期ピーク)**を出し、その後は力が下がる。ピークを削るには壁側を弱く、奥ほど強く(段階的に)。
- 並列に並べると力は足し算、直列に並べると**弱い所から順に潰れる**。
- オフセット衝突・ポール衝突では、**荷重の通り道に入らない材料はただの重り**。

## 物理モデル(`js/solver.js`)
- セルごとに格子(辺4本+対角2本)を作り、節点と**軸力のみのバー要素**で構成する2D陽解法動力学(symplectic Euler、dt ≈ 2e-5 s)。
- バーの力-変位則(経路依存): 弾性 → 強度 P で座屈 → 力がプラトー(0.6 P)へ低下 → 70%潰れた所で底づき(再び硬くなる)/ 引張は弾塑性、大きく伸びると破断。
- 節点は上下の壁(通路)で拘束。壁(バリア)は左側、ステージによって一部のみ(オフセット/ポール)。乗員室は剛体で、接続板はx方向のみ動く。
- 最大Gは3 ms の移動平均(人体への影響を見るため)。

## ステージ
1. 正面衝突(50 km/h、潰れ代 80 cm)
2. 高速・短い潰れ代(58 km/h、65 cm)
3. オフセット衝突(壁は下半分のみ)
4. ポール衝突(壁は中央の幅10 cmのみ)
