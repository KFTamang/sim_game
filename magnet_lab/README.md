# Magnet Lab — 磁束を導き、集め、遮る

鉄と磁石をセルに塗って、**磁気回路**を設計するゲーム。磁力線と磁束密度がリアルタイムに見える。

## 遊び方
`index.html` をブラウザで開く(ビルド不要)。ドラッグで塗る・右クリックで消す。

| # | ステージ | 内容 | 身につく直感 |
|---|---|---|---|
| 1 | 磁気ギャップ | 磁石の磁束を測定ゾーンへ導く | 磁束は閉じた輪。**戻りの道**が要る/近すぎると**短絡** |
| 2 | 磁気シールド | 外部磁場(0.3 T)から中央を守る | 鉄は磁束を吸い込んで迂回させる。**薄い殻を何重か**が有利、厚い1枚は飽和 |
| 3 | 磁束の集中 | 大きな磁石の磁束を小さなギャップへ絞る | **先細りの磁極**で磁束密度が上がる。鉄は約1.6 Tで**飽和** |
| 4 | 片側だけ磁場 | 磁石の向きを自由に並べる | 90°ずつ回す**ハルバッハ配列**で片側に強め合い、反対側は打ち消し合う |

スコア = 目標を満たしたうえでの 性能 ÷ 材料コスト(軽く作るほど高得点)。

## 物理モデル(`js/solver.js`)
- 2D静磁場。面外ベクトルポテンシャル A を解く: `−∇·(ν∇A) = ∇·(ν Br⊥)`、`B = (−∂A/∂y, ∂A/∂x)`、ν = 1/(μ0 μr)。
- 有限体積法(セル間は ν の調和平均)。永久磁石は残留磁束密度 Br = 1.2 T の源項。面をまたぐ接線 H の連続性から、面の源項は `g_face × mean(Br⊥)`。
- 外枠は A を指定(磁束が外へ出ない箱)。一様な外部磁場も境界値で与える。
- 鉄は非線形: `μ0 H = B/μr0 + Hs (B/Bs)^q`(μr0 = 800、Bs = 1.6 T)。Bk(≈2.2 T)を超えると空気と同じ傾きになる。**|B| に対する緩和付きの逐次代入**で収束させ、各線形ステップは Jacobi-PCG(ウォームスタート)。
- 磁力線は A の等高線(marching squares)。
