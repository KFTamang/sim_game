# Heat Lab(熱の通り道)

`sim_game` の第2作。全面で発熱する基板に、限られた予算で高伝導材(アルミ・銅)を塗り、
放熱窓までの**熱の通り道**を設計して最高温度を下げます。

- ドラッグで塗る / 右クリックで消す / Shift+ドラッグで直線
- 温度分布と**熱の流れ**(点々の流れ)をリアルタイムに表示。材料の中は速く、樹脂の中は遅い
- **冷却倍率** = 材料なしの最高温 ÷ あなたの最高温
- **スコア** = (冷却倍率 − 1) ÷ コスト × 10000(目標倍率以上・予算内のときのみ。提出で記録)
- 材料: アルミ(熱伝導率 樹脂の100倍・コスト1)/ 銅(250倍・コスト3)
- ステージ: チップ冷却 / 角の放熱点 / ホットスポット / 穴あきボード(断熱の穴を避ける)
- 提出後に結果を X へ投稿するボタン

### 遊び方

`index.html` をブラウザで開くだけ(ビルド不要、外部依存なし)。
ローカルサーバで開く場合は、このフォルダで `npm run serve` → http://localhost:8000

| 操作 | 内容 |
|---|---|
| 1 / 2 | アルミ / 銅 |
| E | 消しゴムの切り替え |
| [ / ] | 筆の太さ |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |

### 物理モデル

2次元の定常熱伝導(ポアソン方程式)

    div( k grad T ) = -q       放熱窓: T = 0、他の辺: 断熱

- セル中心の有限体積法。隣り合うセルの熱コンダクタンスは熱伝導率の**調和平均**
- 連立一次方程式は対称正定値 → ヤコビ前処理つき共役勾配法(CG)。前回の解を初期値にして対話的に更新
- 1次元の解析解(`T_max = qN²/2k`)、熱収支(発熱 = 放熱)をテストで検証
- 結果として、根元が太く先端が細い**枝分かれ(樹状)構造**が効率の良い解になる
